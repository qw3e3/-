# كفاءات

واجهة أولية لمنصة عربية ثنائية اللغة للوظائف والخدمات. تعرض المنصة الفرص علناً، وتطبّق حاجز اشتراك تفاعلي قبل الإجراءات التنفيذية.

## التشغيل

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`. يتضمن مخطط Prisma نماذج للحسابات والمحافظ والضمان مع SQLite للمعاينة المحلية؛ يبدّل الإنتاج إلى PostgreSQL عبر `DATABASE_URL` ومزوّد Prisma المناسب.
